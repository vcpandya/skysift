What it does: how many stars this sweep takes from the source's list, highest priority first. Stars already searched are skipped. Default 500.

What it does: the shortest time between two dips that the search tries. Default {{ "%g" | format(th.min_period_days) }} days.

What it does: the longest time between two dips that the search tries. A wider window takes longer and needs its own threshold calibration. Default {{ "%g" | format(th.max_period_days) }} days.

What it does: stream deletes each light curve once its star is vetted, keep keeps them all, budget keeps them until the cache reaches the size below. Evidence for a kept signal is never deleted. Default {{ retention_now }}.

What it does: with budget only, the most disk space the downloaded files may take. Default 50 GiB.

What it does: how many light curves download at the same time. Default {{ settings.workers_io }}.

What it does: how many stars are searched at the same time, one processor core each. Default {{ settings.workers_cpu }}.

What it does: skips stars fainter than this G magnitude (brightness in Gaia's G band, bigger is fainter). A larger number lets fainter stars in. Default 19.

What it does: keeps the periodogram (the strength of every trial period), about 8 kB a star, so the signal page can draw it. Default {{ periodogram_labels.get(settings.store_periodogram, settings.store_periodogram) }}.

What it does: skips the stars Kepler's own pipeline already searched. Default on.
